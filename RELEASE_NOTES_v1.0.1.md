## Inuyaxs Server Management v1.0.1

### ✨ Novedades
- 🌐 Nueva tarjeta con la **IP local** del servidor y botón de copiar.
- 🔗 Muestra la **IP pública de Playit.gg** cuando el túnel está activo.
- 📊 La tarjeta del servidor ahora muestra la **RAM usada** en tiempo real.

### 🐛 Correcciones
- Arreglado el error que impedía iniciar el servidor (`dl failure` / `libc++_shared.so not found`). Si ya tenías Java instalado, se repara automáticamente al iniciar el servidor (necesita internet esa primera vez).

### 📲 Instalación
Descarga el APK de abajo, ábrelo y permite instalar desde fuentes desconocidas si Android lo pide.
Requiere Android 5.0+ y un procesador de 64 bits (arm64-v8a).
